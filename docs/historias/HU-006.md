# HU-006: Uso offline, sin inicio de sesión ni publicidad

## Estado

**Borrador. Pendiente de contrastar con el enunciado original antes de su aprobación.**

Esta historia no autoriza planificación técnica ni implementación.

## Historia de usuario

Como estudiante de Academia Cotopaxi, quiero utilizar la aplicación sin iniciar sesión, sin publicidad y sin conexión a Internet para acceder directamente al temporizador y mantener la concentración.

## Objetivo

Garantizar que las funciones definidas en HU-001 a HU-005 sean locales y no dependan de una cuenta, anuncios o conexión a Internet.

## Alcance confirmado para revisión

- Acceso sin registro, autenticación ni inicio de sesión.
- Ausencia de publicidad.
- Funcionamiento sin conexión de temporizador, ciclos, recuperación, avisos locales y configuración.
- Conservación local de la información necesaria para esas funciones.

## Requisitos EARS preliminares

- **HU-006-R01 (ubícuo):** La aplicación no deberá exigir registro, autenticación ni inicio de sesión para utilizar sus funciones.
- **HU-006-R02 (ubícuo):** La aplicación no deberá mostrar ni descargar publicidad.
- **HU-006-R03 (dependiente de estado):** Mientras el dispositivo no tenga conexión a Internet, la aplicación deberá permitir utilizar las funciones definidas en HU-001 a HU-005.
- **HU-006-R04 (ubícuo):** La aplicación deberá conservar localmente la información necesaria para temporizador, ciclos, recuperación y configuración.
- **HU-006-R05 (comportamiento no deseado):** Si no hay conexión a Internet, la aplicación no deberá bloquear el inicio ni la operación de una función esencial.
- **HU-006-R06 (ubícuo):** La aplicación no deberá incorporar rastreo, telemetría ni transferencia de datos sin una decisión explícita y aprobada, conforme a la constitución.

## Criterios de aceptación preliminares

### HU-006-CA01: Primera apertura sin conexión

**Dado** que la aplicación se abre por primera vez con el dispositivo sin conexión a Internet,  
**Cuando** el usuario accede a ella,  
**Entonces** puede llegar al temporizador sin registrarse, autenticarse ni esperar una respuesta de red.

### HU-006-CA02: Control del temporizador offline

**Dado** que el dispositivo no tiene conexión a Internet,  
**Cuando** el usuario inicia, pausa, reanuda o solicita reiniciar una fase,  
**Entonces** la acción conserva el comportamiento definido en HU-001.

### HU-006-CA03: Ciclo completo offline

**Dado** que el dispositivo no tiene conexión a Internet,  
**Cuando** el usuario completa fases de estudio y descanso,  
**Entonces** el ciclo y el inicio manual de cada fase conservan el comportamiento definido en HU-002.

### HU-006-CA04: Recuperación offline

**Dado** que el dispositivo no tiene conexión a Internet y existe un estado conservado,  
**Cuando** el usuario bloquea el celular o cierra y reabre la aplicación,  
**Entonces** la recuperación conserva el comportamiento definido en HU-003.

### HU-006-CA05: Avisos locales offline

**Dado** que el dispositivo no tiene conexión a Internet y Android permite los avisos locales,  
**Cuando** una fase termina,  
**Entonces** la aplicación solicita los avisos definidos en HU-004 sin usar un servicio remoto.

### HU-006-CA06: Configuración offline

**Dado** que el dispositivo no tiene conexión a Internet,  
**Cuando** el usuario consulta, valida, guarda o restaura duraciones,  
**Entonces** la configuración conserva el comportamiento definido en HU-005.

### HU-006-CA07: Sin inicio de sesión

**Dado** que el usuario recorre cualquier función de la aplicación,  
**Cuando** intenta utilizarla,  
**Entonces** no encuentra un requisito de registro, autenticación o inicio de sesión.

### HU-006-CA08: Sin publicidad

**Dado** que el usuario recorre cualquier función de la aplicación con o sin conexión,  
**Cuando** visualiza o utiliza la interfaz,  
**Entonces** no se muestra, solicita ni descarga publicidad.

## Dependencias

- HU-001 a HU-005 definen las funciones que deben operar sin conexión.
- La constitución define las restricciones de privacidad y transferencia de datos.
