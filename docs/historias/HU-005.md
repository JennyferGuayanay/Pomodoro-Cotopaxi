# HU-005: Configuración y persistencia de duraciones

## Estado

**Borrador. Pendiente de contrastar con el enunciado original antes de su aprobación.**

Esta historia no autoriza planificación técnica ni implementación.

## Historia de usuario

Como estudiante de Academia Cotopaxi, quiero configurar, validar y guardar las duraciones de estudio, descanso corto y descanso largo, y restaurar sus valores predeterminados, para adaptar los ciclos sin alterar la fase actual.

## Objetivo

Mantener una configuración local válida con valores predeterminados de 25, 5 y 15 minutos, aplicada desde la siguiente fase y con descanso largo cada cuatro pomodoros.

## Alcance confirmado para revisión

- Duración de estudio configurable, con valor predeterminado de 25 minutos.
- Duración de descanso corto configurable, con valor predeterminado de 5 minutos.
- Duración de descanso largo configurable, con valor predeterminado de 15 minutos.
- Descanso largo después de cuatro pomodoros de estudio completados.
- Validación de entradas antes de guardar.
- Persistencia local de valores válidos.
- Restauración explícita de los valores predeterminados.
- Aplicación de cambios guardados desde la siguiente fase, sin modificar la fase actual.

## Requisitos EARS preliminares

- **HU-005-R01 (ubícuo):** La aplicación deberá proporcionar duraciones separadas para estudio, descanso corto y descanso largo.
- **HU-005-R02 (ubícuo):** En ausencia de una configuración válida guardada, la aplicación deberá usar 25 minutos para estudio, 5 minutos para descanso corto y 15 minutos para descanso largo.
- **HU-005-R03 (dirigido por evento):** Cuando el usuario intente guardar la configuración, la aplicación deberá validar cada entrada antes de persistirla.
- **HU-005-R04 (comportamiento no deseado):** Si una entrada no cumple las reglas de validación aprobadas, la aplicación deberá impedir el guardado y comunicar qué valor debe corregirse.
- **HU-005-R05 (dirigido por evento):** Cuando el usuario guarde duraciones válidas, la aplicación deberá conservarlas localmente.
- **HU-005-R06 (dirigido por evento):** Cuando la aplicación vuelva a abrirse, deberá recuperar las duraciones válidas guardadas.
- **HU-005-R07 (dependiente de estado):** Mientras una fase actual esté disponible, en ejecución o pausada, los cambios guardados no deberán modificar su duración.
- **HU-005-R08 (dirigido por evento):** Cuando comience la siguiente fase después de guardar cambios válidos, la aplicación deberá usar la nueva duración correspondiente a su tipo.
- **HU-005-R09 (dirigido por evento):** Cuando el usuario seleccione restaurar los valores predeterminados, la aplicación deberá guardar 25, 5 y 15 minutos y aplicarlos desde la siguiente fase.
- **HU-005-R10 (ubícuo):** La aplicación deberá seleccionar el descanso largo después de cada grupo de cuatro pomodoros de estudio completados.
- **HU-005-R11 (dependiente de estado):** Mientras el dispositivo no tenga conexión a Internet, la consulta, validación, persistencia y restauración de la configuración deberán funcionar localmente.

## Criterios de aceptación preliminares

### HU-005-CA01: Valores predeterminados iniciales

**Dado** que no existe una configuración válida guardada,  
**Cuando** la aplicación necesita las duraciones del ciclo,  
**Entonces** usa 25 minutos para estudio, 5 minutos para descanso corto y 15 minutos para descanso largo.

### HU-005-CA02: Guardado de valores válidos

**Dado** que el usuario introdujo valores que cumplen todas las reglas de validación aprobadas,  
**Cuando** selecciona guardar,  
**Entonces** la aplicación conserva localmente las tres duraciones.

### HU-005-CA03: Rechazo de valores inválidos

**Dado** que al menos una entrada no cumple las reglas de validación aprobadas,  
**Cuando** el usuario intenta guardar,  
**Entonces** la aplicación no reemplaza la configuración guardada e identifica de forma accesible el valor que debe corregirse.

### HU-005-CA04: Persistencia después de reabrir

**Dado** que el usuario guardó duraciones válidas,  
**Cuando** cierra y vuelve a abrir la aplicación,  
**Entonces** la aplicación muestra y utiliza los valores guardados.

### HU-005-CA05: Cambios desde la siguiente fase

**Dado** que existe una fase actual y el usuario guarda nuevas duraciones válidas,  
**Cuando** la fase actual continúa, se pausa o se reanuda,  
**Entonces** conserva la duración que tenía antes del cambio y la nueva configuración se reserva para la siguiente fase.

### HU-005-CA06: Aplicación del cambio

**Dado** que el usuario guardó nuevas duraciones durante una fase anterior,  
**Cuando** queda disponible la siguiente fase,  
**Entonces** esa fase utiliza la nueva duración correspondiente y espera el inicio manual definido por HU-002.

### HU-005-CA07: Restauración de valores predeterminados

**Dado** que existen duraciones personalizadas,  
**Cuando** el usuario selecciona restaurar los valores predeterminados,  
**Entonces** la aplicación guarda 25, 5 y 15 minutos y los aplica desde la siguiente fase.

### HU-005-CA08: Descanso largo cada cuatro pomodoros

**Dado** que se han completado cuatro pomodoros de estudio en el grupo actual,  
**Cuando** la aplicación determina la siguiente fase,  
**Entonces** selecciona un descanso largo con la duración configurada para ese tipo.

### HU-005-CA09: Configuración offline

**Dado** que el dispositivo no tiene conexión a Internet,  
**Cuando** el usuario consulta, valida, guarda o restaura las duraciones,  
**Entonces** la operación se completa localmente con el mismo comportamiento funcional.

## Dependencias

- HU-001 consume la duración de la fase actual.
- HU-002 consume la duración correspondiente a cada tipo de fase y gestiona el grupo de cuatro.
- HU-003 conserva la configuración y los cambios pendientes de aplicación.
- HU-006 exige operación local sin cuenta ni conexión.
